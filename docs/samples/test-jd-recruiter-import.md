# TUYỂN DỤNG SENIOR FULLSTACK DEVELOPER (REACT / SPRING BOOT)

- **Vị trí / Chức danh:** Senior Fullstack Developer (React & Java/Spring Boot)
- **Lĩnh vực:** Công nghệ
- **Phòng ban:** IT
- **Cấp bậc:** Senior
- **Số lượng tuyển dụng:** 2 người
- **Hình thức làm việc:** Hybrid (3 ngày tại văn phòng, 2 ngày WFH)
- **Địa điểm làm việc:** Đà Nẵng
- **Loại hình công việc:** Toàn thời gian (FULL_TIME)
- **Mức lương:** 32.000.000 – 48.000.000 VNĐ (Thỏa thuận theo năng lực)
- **Hạn nộp hồ sơ:** 2026-12-31

---

## 1. Mô tả công việc (Job Description)
- Chịu trách nhiệm kiến trúc, phát triển và tối ưu hóa các ứng dụng web quy mô lớn phục vụ hàng trăm nghìn người dùng.
- Xây dựng giao diện người dùng hiện đại, trực quan, tối ưu trải nghiệm (UX) và hiệu năng hiển thị (Core Web Vitals) bằng React 19, TypeScript và Vite.
- Thiết kế và cài đặt hệ thống RESTful APIs, vi dịch vụ (Microservices) chịu tải cao với Spring Boot 3 và Java 21.
- Tối ưu hóa hiệu năng cơ sở dữ liệu quan hệ (PostgreSQL) và bộ nhớ đệm (Redis), giải quyết các bài toán về khóa giao dịch (locks, isolation) và tốc độ truy vấn.
- Phối hợp chặt chẽ với Product Owner, Designer và đội ngũ AI để tích hợp các mô hình trí tuệ nhân tạo (LLM, RAG) vào luồng nghiệp vụ thực tế.
- Hướng dẫn, hỗ trợ kỹ thuật (mentoring) và thực hiện review mã nguồn (code review) cho các thành viên Junior và Middle trong nhóm.

---

## 2. Yêu cầu ứng viên (Requirements)
- Tốt nghiệp Đại học chuyên ngành Công nghệ Thông tin, Kỹ thuật Phần mềm hoặc các ngành liên quan.
- Tối thiểu 4 năm kinh nghiệm lập trình thực tế với Java / Spring Boot và React / TypeScript.
- Thành thạo kiến trúc Microservices, RESTful API design, Spring Security, Hibernate / Spring Data JPA.
- Nắm vững kiến thức chuyên sâu về Frontend: React Hooks, State Management, Responsive Design, CSS module / TailwindCSS, SSR/SSG.
- Kinh nghiệm làm việc vững chắc với hệ quản trị cơ sở dữ liệu PostgreSQL, tối ưu hóa câu lệnh SQL, indexing và replication.
- Thành thạo công cụ kiểm thử: JUnit 5, Mockito, Jest hoặc React Testing Library.
- Có kinh nghiệm thực tế với Docker, Docker Compose, CI/CD pipeline (GitHub Actions/GitLab CI).
- Kỹ năng giải quyết vấn đề (problem-solving) tốt, tư duy hệ thống và khả năng giao tiếp tiếng Anh đọc hiểu tài liệu chuyên ngành tốt.

---

## 3. Quyền lợi được hưởng (Benefits)
- Mức thu nhập cạnh tranh: Lương cứng từ 32 – 48 triệu VNĐ/tháng + Thưởng hiệu suất dự án hàng quý.
- Thưởng tháng lương thứ 13, 14 và thưởng lễ Tết hấp dẫn.
- Gói bảo hiểm sức khỏe toàn diện cao cấp (Bảo Việt / PVI) dành cho nhân viên và người thân.
- Phụ cấp ăn trưa, gửi xe và ngân sách 15.000.000 VNĐ trang bị thiết bị làm việc (MacBook Pro / màn hình 4K).
- Chế độ làm việc linh hoạt (Hybrid), 14 ngày phép năm + ngày nghỉ sinh nhật hưởng nguyên lương.
- Môi trường làm việc trẻ trung, sáng tạo, hỗ trợ 100% chi phí các chứng chỉ quốc tế (AWS, OCP, Google Cloud).

---

## 4. Tiêu chí đánh giá trọng tâm (Assessment Criteria)
1. **Kinh nghiệm chuyên môn (EXPERIENCE - 40%):** Tối thiểu 4 năm phát triển hệ thống với Java Spring Boot và ReactJS.
2. **Kiến thức kiến trúc & cơ sở dữ liệu (EXPERIENCE - 25%):** Nắm vững thiết kế Microservices, tối ưu truy vấn PostgreSQL và Redis caching.
3. **Chất lượng mã nguồn & Kiểm thử (OTHER - 15%):** Thói quen viết Clean Code, thành thạo Unit Test và Git workflow.
4. **Học vấn & Bằng cấp (EDUCATION - 10%):** Bằng Cử nhân CNTT hoặc chứng chỉ chuyên nghiệp tương đương.
5. **Ngoại ngữ & Kỹ năng mềm (LANGUAGE - 10%):** Tiếng Anh đọc hiểu tài liệu kỹ thuật tốt, khả năng làm việc nhóm và giao tiếp hiệu quả.
